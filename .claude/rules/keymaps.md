# キーマップ規約

## ドキュメント更新必須

**キーバインドや操作を追加した場合は必ず`KEYMAPS.md`に記録する**

## ドキュメント形式

`KEYMAPS.md`は以下の構造に従います：

### セクション

- アプリケーション名（例: Neovim, Claude Code, zsh）
- 機能カテゴリ（例: 診断、コメント、ターミナル操作）

### エントリ形式

```markdown
## [カテゴリ名]

- キーバインド: 説明
  - コマンド: [オプション] コマンド名
  - 使い方: [オプション] 詳細な使用方法
```

## 例

```markdown
## ターミナル操作

### toggletrm

- <leader>tc: ターミナル画面とスクロールバック（履歴）を両方クリア
    - 使い方: ターミナルモード（t）で実行。`reset`コマンドの代わりに使う
```

## 更新ワークフロー

1. 新しいキーバインドを設定ファイルに追加
2. 動作確認
3. `KEYMAPS.md`にエントリを追加
4. コミット（CLAUDE.mdのコミットメッセージ規約 = Conventional Commits に従う）

## 注意事項

- 既存のキーバインドとの競合を確認
- 直感的でアクセスしやすいキーを選択
- リーダーキー（`<leader>`）を活用
